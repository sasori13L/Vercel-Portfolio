# Portfolio

A responsive, single-page professional portfolio site.

## Tech stack

- Next.js for the application framework
- HTML5 for semantic page structure
- CSS3 for layout, styling, and responsive design
- Vanilla JavaScript for mobile navigation and scroll-reveal interactions
- Google Fonts: Fraunces, IBM Plex Mono, and Inter
- Vercel for static-site hosting
