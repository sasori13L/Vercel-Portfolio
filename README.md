# Lyla Chairein Quintana — Portfolio

A one-page portfolio built with Next.js App Router. The page is implemented in `app/page.jsx`, with the blueprint design system in `app/globals.css` and page metadata in `app/layout.jsx`.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Build for deployment

```bash
npm run build
npm run start
```

Vercel detects Next.js automatically when this repository is imported.
